TCP Reno Mathematical Update Rules
Slow Start (cwnd < ssthresh): cwnd = cwnd * 2 per RTT (+1 MSS per ACK).
Congestion Avoidance (cwnd ≥ ssthresh): Additive Increase: cwnd = cwnd + 1 per RTT.
3 Duplicate ACKs (Fast Recovery): ssthresh = max(2, cwnd/2), cwnd = ssthresh + 3.
Timeout Event (RTO): Severe loss: ssthresh = max(2, cwnd/2), cwnd = 1.0, reset to Slow Start.

Scheduling Policy & Starvation Characteristic

In high-volume banking systems, financial transfers and user wire authorizations must never be blocked by background non-urgent batch tasks (e.g. statement downloads). NexaBank implements a 3-tier priority scheduler. Note on Starvation: Under sustained extreme High Priority load, lower priority requests remain buffered; NexaBank rate limits synthetic load to ensure queue draining within bounded limits.

Token Bucket vs Leaky Bucket (Viva Guide)

Token Bucket: Tokens accumulate up to capacity B. Allows bursts of up to B requests instantly, then enforces a steady average rate R.

Leaky Bucket: Drops excess burst instantly, enforcing a strict constant outflow rate without burst allowance.
